## 进入设置、保存与搜索

从 **LSPosed → FocusRestore 模块详情 → 设置** 进入；模块不提供桌面图标。底部有“主页”“高级”“关于”三个页面，具体功能选项集中在“高级”页。

设置会自动保存，无需另按保存按钮。文字输入、拖动与文件操作可能需要短暂等待，请以界面保存状态或错误提示为准。部分选项需要重新加载 SystemUI 才能完整生效，尤其是系统模式切换和模块更新。

右上角搜索支持设置名称、说明及关键词，可输入多个词。点击结果会跳转到对应页面、展开分组并高亮目标。搜索不会替你开启依赖开关；置灰项仍需先满足所在分组说明的条件。

分组标题可展开或收起。带“默认”或“跟随系统”操作的数值项，可以点击相应文字恢复；关闭总开关通常会保留子项数值。下拉选项文字居中，弹层按最长选项与两侧等量留白确定宽度，窗口右缘对齐整行，保留圆角与当前值后的上下三角。短按横幅与旧版点击有额外的互斥规则，见下文。

## 首页：系统模式与加载状态

| 项目 | 默认值或内容 | 说明 |
| --- | --- | --- |
| 系统界面版本模式 | HyperOS 3 | 手动选择 HyperOS 3 或 HyperOS 4；不会根据设备信息自动切换。切换后手动重启系统界面或设备。 |
| 当前加载状态 | 由运行中的 SystemUI 回报 | 用于核对实际加载的模块和模式。覆盖安装后，正在运行的 SystemUI 仍可能保留旧 Hook。 |
| 设备信息 | Android 版本、已安装的 SystemUI 版本、设备型号 | 展示信息，不决定适配模式。已安装版本与正在运行的 Hook 加载状态需分别核对。 |
| 白名单概览 | 两份名单中的应用数 | 管理入口在“高级”页；强制转换与超时豁免互相独立。 |

首次使用需在 LSPosed 中启用模块，并仅勾选 `com.android.systemui` 作用域。安装、重载及日志抓取步骤见[项目说明](../README.md#安装与使用)。

## 高级：超级岛转换

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 转换超级岛内容为焦点通知 | 开启 | 尝试读取符合条件的超级岛内容并转换为 Focus。原生焦点默认优先，不保证所有应用的通知都能转换。 |
| 强制转换白名单 | 空 | 需开启转换开关。名单内应用存在可转换内容时优先转换；不为缺少可读内容的通知生成内容。 |

解析范围、彩色文字和连接符在“内容解析与拼接”中设置。转换开关只控制内容转换；关闭它不等于恢复原生超级岛显示。

通话、录屏、投屏等原生重要提示保留系统处理。强制转换白名单与“超时豁免白名单”用途不同，加入其中一份不会自动加入另一份。

## 高级：显示宽度与时长

| 设置 | 默认值 | 范围与效果 |
| --- | --- | --- |
| 限制焦点通知宽度 | 开启 | 开启后使用横竖屏各自的最大显示宽度；关闭后跟随系统，保留已保存数值。 |
| 最大宽度（竖屏） | 160 dp | 80～400 dp。 |
| 横屏最大宽度 | 600 dp | 80～1600 dp。 |
| 最大显示时间 | 0：不限制 | 设置上限时为 2～3600 秒，支持两位小数；留空或设为 0 恢复不限制。 |
| 超时豁免白名单 | 空 | 名单内应用不受模块最大显示时间限制，仍按系统原有规则显示。 |

最大显示时间从焦点实际显示时开始计算；同一通知的普通内容更新不会不断延长时间，新一代通知重新计时。到期只隐藏模块焦点，通知仍保留在通知栏中。

显示宽度与触控范围分别设置。增大触控范围不会放宽文字显示上限；显示宽度也不是横幅卡片宽度。

## 高级：图标与分隔线

### 图标来源与颜色

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 焦点图标优先级 | 应用图标 → 焦点专用图标 → 超级岛解析图标 → 通知小图标 | 四项均参与按住整行拖动排序；某个来源不可用时继续尝试后面的来源。设备通知图标仍独立处理。 |
| 超级岛解析图标与通知小图标跟随状态栏反色 | 开启 | 解析岛图两种背景共用普通岛图引用，仅缺普通引用时统一回退深色引用，不随明暗切换到缩略图。近似单色解析岛图不论原本色相，跟随系统状态栏前景着色，不设估计对比度门槛。分类只统计原图绘制区域中alpha≥128的像素：有效覆盖率至少5%，16级RGB量化最大桶中心的距离64内像素至少占90%。同色系渐变与最多10%离群颜色可归入主色；未通过的多色或低覆盖率素材保留原图。不自动剔除黑白像素，不要求原图带透明底；平均色仅作诊断，实际染色仍使用状态栏前景。着色只替换RGB，透明孔洞和抗锯齿透明度保留。通知小图标沿用单色着色；应用图标保留原色，焦点专用图标沿用通知提供的浅深版本。 |
| 设备通知图标跟随状态栏反色 | 开启 | 单独控制设备通知图标；关闭后保留原色，不参与上方排序。 |

独立的岛图启用开关已删除。升级或导入旧备份时，原来开启的把解析岛图置首，原来关闭的置末，其他三项相对顺序不变；迁移后只保存四项顺序，不再保存或导出旧开关。新备份完整保留四项排列，旧 App 不保证能识别新增顺序编码。

通知小图标 `smallIcon` 依赖应用适配。部分应用没有提供适合状态栏的单色透明图标，反色后可能出现大白块；可将应用图标或焦点专用图标排在前面，或关闭对应反色。

### 图标尺寸与分隔线

| 设置 | 默认值 | 自定义范围 |
| --- | --- | --- |
| 焦点图标尺寸 | 跟随系统 | 1～32 dp。 |
| 图标与文字间距 | 跟随系统 | 0～24 dp。 |
| 显示焦点分隔线 | 开启 | 控制时间与焦点之间的分隔线；关闭后保留样式和尺寸。 |
| 分隔线样式 | 竖线 | 竖线、圆点、斜线、横线。 |
| 分隔线前间距 | 跟随系统 | -24～24 dp；负值允许相邻内容重叠。 |
| 分隔线后间距 | 跟随系统 | -24～24 dp；负值允许相邻内容重叠。 |
| 分隔线粗细 | 跟随系统 | 1～4 dp。 |

“跟随系统”会尽量读取当前 ROM 的资源，界面展示对应参考数值；不同 ROM 的值可能不同。拖动滑块后变为自定义值，可点击“跟随系统”恢复。

分隔线子项需先开启“显示焦点分隔线”。对应类型开启“隐藏状态栏时间”时，时间旁的分隔线也会一并隐藏。

## 高级：内容解析与拼接

“焦点内容模式”和“渲染彩色字体”需先开启“转换超级岛内容为焦点通知”才能调整。连接符允许单独编辑，在相应文字拼接路径中使用。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 焦点内容模式 | 展开全文本解析 | 优先显示首条成功生成非空正文的已启用规则。缺少有效结果时使用内置全文或原计时。“药丸左右拼接”（简略）依旧取两侧并去重。适用于已准入的超级岛转换。 |
| 渲染彩色字体（`<font color>`） | 开启 | 按文本中的 `<font color='#RRGGBB'>` 标记显示对应颜色；关闭后保留原始标记文本。 |
| 普通内容连接符 | `·` | 模块拼接普通文字片段时使用，允许留空；不改写通知自带的文本布局。 |
| 左右区域连接符 | `·` | 拼接超级岛左、右区域文字时使用，允许留空。 |

## 高级：点击与手势

### 短按与横幅背景

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 点击焦点通知展开横幅（实验性） | 开启 | 下文简称“点击展开横幅”；短按焦点时展开横幅，媒体的点击方式在“媒体焦点”分组单独选择。 |
| 横幅背景 | 统一使用纯色背景 | 需开启点击展开横幅，可选择“统一使用纯色背景”或“使用普通通知背景”。媒体使用封面背景。 |
| 高级材质接入（实验性） | 关闭 | 需开启点击展开横幅并选择“使用普通通知背景”。尝试跟随系统模糊或玻璃材质；关闭或系统不支持时保留原背景。 |

高级材质依赖具体 ROM 和系统材质状态，不能通过此开关强制系统进入 GLASS。符合条件的 OS3 非媒体横幅使用焦点 HUN 的三组主题混色，成功应用时改用 ROM 透明 HUN 背景；没有模糊时保留对应主题的焦点背景。公开内容、透明或自定义背景、通知行缺失或代次不符，以及资源不全时保留兼容路径。

OS4 仅在已核对的 SystemUI `17.03.260226.r / code202602260` 中，被动观察原生 HUN effect 成功返回时传入的玻璃参数；仅缓存当前配置的数值副本，不借用原生通知 View、不内置反编译参数表。当前配置样本与完整 HUN 资源在本次创建前均已就绪时，横幅可使用 HUN 玻璃参数和透明背景。原生 Modal 按既有策略选择；应用自带 RemoteViews 独立按系统日夜选择：浅色优先 `miui.focus.rv`，深色优先 `miui.focus.rvNight`，资源 Context 匹配实际选中的模板；缺某个模板时保留原有兼容回退。应用可在 RemoteViews 中预先写入颜色，独立窗口没有原生 HUN 的完整正文重绑定链，不能仅更换 Context 就宣称文字已适配。

OS4 冷启动第一条可能尚无样本；缺样本、配置变化、未核对的版本或通知例外时，保留既有 GLASS 参数和背景 alpha 上限 51；Modal 仍优先 Dark Modal，应用自带 RemoteViews 始终按上述系统日夜策略选择，与样本是否就绪无关。每次创建时固定新旧配方，迟到样本只供下一次显示，不切换或收起当前横幅。系统日夜变化使应用自带模板失配时收起旧横幅；原生 Modal 保留既有主题/材质/失败失配检查，下次展开重选。新 HUN 路径不再叠加旧 alpha51；采样窗口、模糊半径、独立装饰层、圆角和清理仍复用现有框架，因此并非整套原生 HUN 像素复刻。媒体封面不受该开关影响。

0.45.5 已移除 HUN 独立开关；旧备份键仍被忽略，新备份不导出，旧 Provider 请求继续保留兼容占位。本次未新增开关、运行依赖或自动 OS 模式切换。

切换回纯色背景或关闭横幅，会使高级材质选项置灰，但保留它独立保存的选择。保留玻璃初始化和尺寸维护，以及 0.45.3 引入的首次显示前有限等待一次稳定遍历；具体首帧与材质观感仍需设备复测，不保证与原生通知完全一致。

### 长按、滑动与空间不足处理

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 长按焦点通知模拟通知列表点击（实验性） | 关闭 | 独立于短按横幅开关；普通通知优先使用真实通知行的打开行为，媒体使用可用的通知或应用打开入口。 |
| 长按时间 | 0.5 秒 | 开启长按后可调，0.2～10 秒，滑块步进 0.1 秒。 |
| 左右滑动切换和收起焦点通知（实验性） | 关闭 | 左滑切到下一条，右滑切到上一条；RTL 布局方向相反。滑到空白位置可收起焦点，再滑动恢复；不取消系统通知。 |
| 空间不足时仅显示焦点图标（OS4，实验性） | 关闭 | 仅 OS4 可调；适用于模块管理的图标与文字布局，不保证处理应用任意自定义 RemoteViews。 |

### 旧版点击兼容

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 旧版：打开通知内容（实验性） | 关闭 | 需先关闭“点击展开横幅”，短按直接尝试打开通知。 |

## 高级：媒体焦点

媒体焦点为实验性功能，实际显示和横幅兼容性因 ROM 而异。

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 启用媒体焦点通知 | 关闭 | 在状态栏显示当前媒体；关闭后保留子项配置。 |
| 简短显示 | 关闭 | 开启后可选择并拖动排序正文中的媒体字段。 |
| 简短显示字段 | 标题 → 副标题 → 文本 → 播放状态 | 可选字段共五类：标题、副标题、文本、应用名、播放状态；应用名默认未选，可关闭全部字段。 |
| 媒体点击方式 | 展开媒体横幅 | 可改为直接展开流转；需同时开启媒体焦点与“点击展开横幅”。 |
| 流转面板 | 妙播 | 可选妙播或安卓原生；用于直接展开流转及媒体横幅内的流转入口。妙播不可用时回退安卓原生。 |

简短显示的字段控制需同时开启媒体焦点和简短显示。字段的显示顺序按拖动结果保存，未选字段不参与拼接。

OS4 媒体焦点跟随系统当前媒体卡片：首次出现或切换媒体时要求处于播放状态，同一媒体暂停后可保留；卡片被移除后不会仅因普通通知更新而重新出现。这不代表所有 OS3/OS4 ROM 都具有相同行为。妙播仍遵循系统原有的隐私确认和可用性判断。

| 设置 | 默认值 | 用途与条件 |
| --- | --- | --- |
| 焦点显示期间隐藏其他通知图标 | 开启 | 仅 OS4 可调；焦点收起后恢复通知图标。 |

## Debug：内部兼容开关

仅 Debug 构建显示，Release 设置页不提供这一分组。日常使用建议保持默认。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 覆盖 `feature.island.debug` | 开启 | 用于超级岛屏蔽的系统属性层兼容处理。 |
| 禁用 `FEATURE_DYNAMIC_ISLAND` | 开启 | 用于超级岛屏蔽的功能缓存层兼容处理。 |

这两个选项与“转换超级岛内容为焦点通知”作用不同，调整后需要重新加载系统界面进行核对。它们在 Debug 页的可见性不改变 Release 的默认屏蔽行为。

## 关于：配置导入与导出

“关于”页的“自定义规则”提供最近记录和已保存规则。捕获默认关闭。新建规则按应用、通知类型及完整字段结构匹配。

在已保存规则中，可按应用名或包名搜索，并按启用状态筛选。支持按正文最近保存、应用名称或启停状态排列列表。执行顺序仍使用规则优先级及声明顺序。只有左侧复选框加入批量选择，全选只作用于筛选后的结果。搜索和筛选不会清空已选条目，批量操作会说明其中多少条不在当前结果中。启用、停用可直接执行，批量删除会提示条目数量并要求确认。没有规则时，可点空态卡片中的「从最近捕获创建」。

规则页的操作按钮使用统一尺寸。编辑为铅笔图标，删除为垃圾桶图标，清除选择为叉号，新增为加号，其余操作保留文字说明。

点规则正文或右侧铅笔打开编辑页。常规字段规则可按组点选标签，并全选、清空或反选。全选保留已选顺序，按界面顺序补到最多 16 项。反选按界面顺序选取原先未选的字段，同样受 16 项限制。已选卡片支持长按排序，勾选多项后长按其中一项可整体移动。编辑页提供实时校验、正文预览、撤销和恢复初始字段。复杂规则保留高级编辑入口。点击底部按钮保存或放弃编辑副本。

“规则迁移”使用当前 `.frpk` 规则包。导入先预览新增、重复和失败条目，同类型的重复规则默认为保留本地，可逐条选择替换。导入完成后显示逐条明细。导出默认清除示例文字，保留字段路径、顺序和类型。取消勾选可原样导出。普通配置备份仅保存用户设置。[字段选择、授权与正文排障](island-rule-body-troubleshooting.md)

配置导入与导出使用系统文件选择器。项目链接和许可证也位于“关于”页。

### 导出

选择“导出配置”，在系统文件选择器中选定保存位置。文件为 UTF-8 JSON，默认命名类似 `FocusRestore-2026-11-15-13_00_00.json`。

备份记录用户设置、图标及媒体字段顺序、两份白名单等配置，不包含运行状态、Hook 就绪标记、搜索关键词或分组展开状态。建议在卸载、更换签名版本或导入其他配置前先导出。

### 导入

1. 选择“导入配置”，通过系统文件选择器打开由模块导出的 JSON 文件。
2. 模块读取并校验格式、字段类型、取值及文件大小；确认弹窗出现后，再决定是否覆盖当前配置。
3. 确认后保存导入结果；出现保存失败提示时先处理错误，再确认当前配置是否已生效。
4. 如果导入改变了系统模式或其他需重载的选项，手动重启系统界面或设备。

导入是**覆盖配置**，缺少的字段使用兼容默认值，不是仅替换文件中出现的项目。取消文件选择、取消确认或文件校验失败时，不应用导入内容。

旧备份的主要兼容行为：

- 缺少横屏显示宽度但提供竖屏宽度时，横屏沿用文件中的竖屏值。
- 缺少自定义触控范围时默认关闭；缺少触控宽度时分别使用竖屏 160 dp、横屏 600 dp。
- 缺少高级材质开关时默认关闭，不因选择普通通知背景而自动启用。
- 旧连接符会作为新普通连接符和左右区域连接符的回退值。

仅支持可识别的配置格式版本，文件上限为 16 MiB，两份应用名单还有合计字符配额。不要将日志、APK 或任意 JSON 当作配置文件导入。导出文件中的软件版本用于标识来源，不用于强制切换当前模块版本。

## 常见设置问题

| 现象 | 检查顺序 |
| --- | --- |
| 修改系统模式后没有变化 | 等待自动保存，手动重启系统界面或设备，再查看首页实际加载状态。 |
| 覆盖安装后表现与新版不同 | 安装完成不等于新 Hook 已加载；核对加载版本与模式，必要时按[日志说明](../README.md#日志抓取)记录加载过程。 |
| 某个设置置灰 | 先检查父开关、OS3/OS4 适用范围及短按横幅与旧版点击的互斥关系。 |
| 想扩大点击区域但不想加宽文字 | 开启自定义触控范围，调整横竖屏触控宽度；显示宽度保持原值。 |
| 高级材质打开后没有玻璃边缘 | 先确认普通通知背景及系统材质状态；该功能仍属实验，不将“开关已开”视为视觉效果已成功。 |
| 通知小图标反色后出现白块 | 将应用图标或焦点专用图标排在前面，或关闭对应反色。 |
| 焦点到时消失，通知仍在 | 这是最大显示时间的设计；需要保留焦点时可延长时长、设为不限制，或加入超时豁免名单。 |
| 导入后原有某些设置被重置 | 导入为覆盖操作，缺少字段会采用兼容默认值；需要时导回事先保存的完整备份。 |

本文根据当前设置界面与配置实现整理；ROM 运行效果仍以实际设备为准。源码核对入口：[设置界面](../app/src/main/java/com/hyperos3/focusrestore/SettingsActivity.java)、[默认值与兼容读取](../app/src/main/java/com/hyperos3/focusrestore/FocusRestoreSettings.java)、[备份格式](../app/src/main/java/com/hyperos3/focusrestore/SettingsBackupCodec.java)。
